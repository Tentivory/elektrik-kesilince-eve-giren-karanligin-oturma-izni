# Elektrik Kesilince Eve Giren Karanlığın Oturma İzni

Bu depo, elektrik kesildiği anda evin içine izinsiz giren **karanlığın** tapu-kadastro ciddiyetinde oturma iznini düzenler.

Işık açmaz. Fatura ödemez. Mühür basar.

## Neden var?

Çünkü karanlık her kesintide evinize giriyor ve siz ona "buyur" bile demiyorsunuz. Bu, mülkiyet hukukuna aykırıdır. Bu yazılım o aykırılığı evrakla meşrulaştırır. Meşrulaştırmak çözmek değildir. Evrak çözümdür.

## Kurulum

```bash
python3 karanlik.py --adres "Örnek Sokak No:12" --oda "mutfak"
```

Python 3 yeter. Başka bir şey istemez. Karanlık da istemez, o zaten gelmiştir.

## Çıktı

Resmi başlıklı, belge numaralı, şartlı, mühürlü bir oturma izni. Örnek şart:

> Çakmak yakmak diplomatik krize yol açar.
